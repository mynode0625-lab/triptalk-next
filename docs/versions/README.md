# 버전 보관

지금 쓰는 문서는 상위 폴더에 있고, 여기에는 **되돌아갈 필요가 있는 시점**만 남긴다.
모든 중간 상태를 쌓지 않는다 — 그 일은 git 이 한다.

| 파일 | 무엇 |
|---|---|
| `상세_v1_초안.html` | 상세 소개서 최초 초안. 은행 블루 팔레트, 표지 제목 「환전 이후」, 목차 링크 없음, 슈퍼SOL 자체 개발 문단 있음 |
| `요약본_v1_초안.html` | 요약본 최초 초안. 표지 슬로건 「여행에서 진짜 쓰는 영어」, 고객 소구로 시작, 한 상황 3분, 비교표 있음 |

## 두 초안은 재구성본이다

세션 스크래치패드의 원본 파일이 지워져, 현재본에서 이후 변경을 되돌려 만들었다.
문구와 구조는 초안과 같지만 **바이트 단위로 동일하다고 보장할 수 없다.**
정확한 최초 버전은 아티팩트의 버전 목록(`draft-1`)에 남아 있다.

- 상세 — https://claude.ai/code/artifact/069bace2-d332-439c-a07f-8833cb03e310
- 요약본 — https://claude.ai/code/artifact/d7eb2a38-97b1-4345-9842-b9a2ab342eb9

## 앞으로

문서를 고칠 때마다 커밋한다. `git log -- docs/` 로 이력을 보고,
`git show <커밋>:docs/<파일>` 로 그 시점 내용을 꺼낸다.
되돌리고 싶으면 `git checkout <커밋> -- docs/<파일>`.
